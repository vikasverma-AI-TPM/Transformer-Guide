# Transformers, Interactively Explained

A single-file, self-contained interactive study guide for the Transformer architecture (attention, encoder/decoder, BERT vs GPT, and more). Everything — HTML, CSS, and JS — lives in `index.html`; there's no build step and no dependencies.

Live Demo:- https://vikasverma-ai-tpm.github.io/Transformer-Guide/

Also deployed on :- https://transformer-interactive-guide.netlify.app/

## What's Inside

→ Interactive walkthroughs of the Encoder & Decoder

→ A hands-on Self-Attention (Q-K-V) demo with real-math calculations, including Positional Encoding

→ Multi-Head, Cross & Masked Attention

→ A sequential vs. parallel simulation comparing RNNs and Transformers

→ Quizzes + mastery tracking

→ A built-in Transformer glossary

→ An end-to-end pipeline trace bringing it all together

Every topic page includes a short quiz with instant feedback.

## Tech Stack

Vanilla HTML, CSS, and JavaScript — no frameworks, no build step, no external dependencies beyond Google Fonts.
